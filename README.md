# 🐍 HYDRA BLOOD

Hub modular para Roblox desenvolvido em Lua/Luau.

## Sobre o projeto

O Hydra Blood é um projeto independente inspirado em interfaces modernas de hubs de Roblox, com identidade visual própria e arquitetura modular.

## Identidade visual

- Tema: Hydra Blood
- Cores: preto, vermelho-sangue e roxo escuro
- Interface: moderna, organizada e responsiva

## Módulos planejados

- Interface principal
- Configurações
- Notificações
- Rastreamento de missões
- Rastreamento de itens
- Ferramentas de diagnóstico
- Utilidades para experiências próprias ou autorizadas

## Desenvolvimento

Os módulos serão adicionados e testados individualmente. Recursos que dependam de funcionalidades do servidor serão implementados em ambientes autorizados.

## Segurança

O projeto não garante ausência de banimento em jogos de terceiros. Nenhum módulo deve contornar mecanismos de segurança ou executar código remoto não verificado.
